# 18 — Atualização da marca: Finaxis

## Pedido

Foi solicitado retirar o “2.0” do nome apresentado ao usuário. O produto deveria passar a se chamar simplesmente **Finaxis**.

## Alterações de identidade visual

O nome visível foi atualizado em:
- tela de login;
- cabeçalho da aplicação;
- barra lateral;
- título do navegador;
- relatórios;
- inicializador do Windows;
- documentação de apresentação.

## Compatibilidade

O identificador interno `Finaxis 2.0` utilizado no formato de backup foi preservado para não invalidar arquivos antigos.

## Resultado

A marca apresentada ao usuário passou a ser Finaxis, mantendo o identificador técnico necessário para reconhecer backups anteriores.
