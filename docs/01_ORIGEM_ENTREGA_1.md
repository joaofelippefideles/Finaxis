# 01 — Origem do projeto: Entrega 1

## O ponto de partida

O Finaxis começou como um projeto de **Sistema de Controle Financeiro Pessoal**, registrado inicialmente como **Entrega 1 — Sistema de Controle Financeiro**.

Essa primeira entrega foi a base para o que veio depois. Em vez de abandonar o trabalho anterior, a evolução foi planejada para aproveitar os recursos e os dados que fossem compatíveis.

## O que sabemos sobre essa versão

A Entrega 1 continha um banco de dados antigo que seria considerado no processo de migração. Na análise registrada posteriormente, o banco disponibilizado continha 11 categorias e nenhum lançamento financeiro.

Esse conteúdo permitiu conhecer parte da estrutura antiga, mas não foi suficiente para comprovar uma migração completa com histórico real de receitas e despesas.

## Por que ela é importante

A Entrega 1 estabeleceu a finalidade do sistema: ajudar a organizar a vida financeira. Ela também criou a necessidade de preservar dados ao evoluir a aplicação.

## Decisão para a continuidade

A nova versão deveria:
- preservar o banco antigo;
- importar somente os dados compatíveis;
- não apagar nem alterar a base original;
- oferecer uma estrutura mais organizada para continuar o desenvolvimento.

## Limite do registro

O histórico disponível não contém uma relação completa de todas as telas, campos e funções da Entrega 1. Por isso, este documento registra o papel da primeira versão sem atribuir a ela funcionalidades que não conseguimos confirmar.
